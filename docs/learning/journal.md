# Keel learning journal

This repository is used to learn backend Go, not only to produce code. This file
is the record of that.

It is written through `/journal` at the end of a session. The rules live in
`.claude/commands/journal.md`, and the most important of them: draw a hard line
between what Al wrote and what Claude wrote, then record understanding debt
honestly. An entry that compliments itself is worthless six months later.

## Format of one entry

Copy the block below. Do not rename its sections.

```markdown
## YYYY-MM-DD

**What changed.** A one paragraph summary from `git log` and `git diff` for that
session.

**Written by Al.** Which files and functions. This is what has to be defensible
when a reviewer or a funder asks.

**Written by Claude.** Which files and functions.

**Today's question.** One question about code Claude wrote.

**Understanding debt.** If the question above went unanswered, write down what is
not yet understood and in which file. Leave this empty only if it really was
answered.
```
