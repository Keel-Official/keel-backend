# Evidence: a USTRY/USDC liquidity pool existed and held reserves at ledger 61340263
#
# Collected 21 August 2026 from Horizon mainnet. Every command below is free, needs
# no account, and can be re-run by anyone. The golden fixture states Pools: [] for
# this ledger; this file is the evidence that it did not.
#
# The chain of reasoning, so a reader can check each link separately:
#   1. a pool for exactly this asset pair exists
#   2. the last transaction to touch it before the incident ledger was 12 days earlier
#   3. pool reserves change ONLY through a transaction touching the pool
#   4. therefore the reserves at ledger 61340263 are the reserves left by that
#      transaction, and they were not zero

# ------------------------------------- 2. the last pool event before the incident
#
# The cursor is a TOID: ledger sequence shifted left 32 bits. 61340264 << 32 gives
# 263454427808006144, so order=desc from that cursor returns what happened
# immediately BEFORE the fixture's ledger.

$ curl -s "https://horizon.stellar.org/liquidity_pools/27480d.../transactions?cursor=263454427808006144&order=desc&limit=1"

  hash       : fa012177007df029feb49d9c62c922d92a1f4ebd90e69269a593778f585ab7bb
  ledger     : 61172481
  created_at : 2026-02-10T16:59:35Z

  That is 12 days before the incident. Nothing touched this pool between then and
  ledger 61340264.

# ------------------------------------------------- 3. the reserves that transaction left

$ curl -s "https://horizon.stellar.org/transactions/fa012177007df029feb49d9c62c922d92a1f4ebd90e69269a593778f585ab7bb/effects"

# ---------------------------------------------------------------- 4. what follows
#
# Reserves at ledger 61340263, the fixture's ledger:
#
#     ReserveQuote (USDC)  = 16.3389179
#     ReserveBase  (USTRY) = 15.4791416
#     FeeBP                = 30
#     spot price           = 16.3389179 / 15.4791416 = 1.0555441847 USDC per USTRY

# The pool was quoting 1.0555, which is the price USTRY is actually worth. The

# The fixture records Pools: nil. That is wrong.

# ------------------------------------- 4b. the same gap checked from the other side
